# Unity Wind & Physics Simulation

## Overview
A Unity 6 outdoor environment demonstrating dynamic wind controls, terrain vegetation, and physics-based object interaction.

## Features
- Outdoor Terrain with trees, grass, lighting, and shadows
- Runtime controls for wind speed, strength, and direction
- Wind direction compass and status indicator
- Wind variation and gust simulation
- Physics objects affected by wind and gravity
- Falling-leaf particle effects, where configured

## Technologies
- Unity 6
- C#
- Unity Terrain
- Particle System
- Rigidbody and Collider
- Unity UI / TextMeshPro

## How to Run
1. Clone or download this repository.
2. Open the project using a compatible Unity 6 editor.
3. Allow Unity to import the assets.
4. Open `Assets/Scenes/WindForest.unity` (adjust if your scene has a different name).
5. Press Play to test the simulation.

## Controls
Use the runtime Wind Control panel to adjust wind speed, strength, and direction.
